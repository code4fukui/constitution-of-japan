# 日本国憲法

本リポジトリでは、日本国憲法の全文をMarkdown形式で提供しています。主な目的は、プルリクエストを用いたバージョン管理のワークフローを通じて、憲法改正に関する議論や提案を促進することです。

## 特徴

- 日本国憲法の全文を1つのMarkdownファイルとして収録: [`日本国憲法.md`](日本国憲法.md)
- Gitのブランチとプルリクエストを利用した、改正案を提案するための構造化されたワークフロー

## 改正案の提案方法

改正案を提案する場合は、以下の手順に従ってください。

1. `master`から**新しいブランチを作成**します。
    - 命名規則: `feature/{proposer_name}-{proposal_name}-YYYY-MM-DD`
2. **憲法ファイルを編集**します。
    - [`日本国憲法.md`](日本国憲法.md)ファイルに直接、提案する変更を加えます。
3. **プルリクエストを作成**します。
    - レビューと議論のため、作成したブランチから`master`ブランチに向けてプルリクエストを提出します。
