# Constitution of Japan

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

This repository provides the full text of the Constitution of Japan in Markdown format. The primary purpose is to facilitate discussion and proposals for amendments through a version-controlled workflow using pull requests.

## Features

- The complete text of the Constitution of Japan in a single Markdown file: [`日本国憲法.md`](日本国憲法.md).
- A structured workflow for proposing amendments via Git branches and pull requests.

## Proposing Amendments

To propose an amendment, please follow this process:

1.  **Create a new branch** from `master`.
    -   Use the naming convention: `feature/{proposer_name}-{proposal_name}-YYYY-MM-DD`
2.  **Edit the constitution file.**
    -   Make your proposed changes directly in the [`日本国憲法.md`](日本国憲法.md) file.
3.  **Create a pull request.**
    -   Submit a pull request from your new branch to the `master` branch for review and discussion.

## Data Source

The text is based on the official version available at the e-Gov Law Search.

- [The Constitution of Japan | e-Gov Law Search](https://elaws.e-gov.go.jp/document?lawid=321CONSTITUTION)
